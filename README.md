# ToDoF

A simple ToDo app I made with C# and WPF.

I originally made this app for myself, and I use it pretty much every day to keep track of school assignments and other things I need to remember.

I'm planning to keep working on it and adding new features as I learn more.

## Features

- Add, edit and remove tasks
- Set dates for tasks
- Calendar view
- See how many tasks are open
- Save and load tasks using a local JSON file
- Confirmation window when saving
- Custom dark-themed UI

## Running the App
1. Download or clone the repository.
2. Open ToDoF.sln in Visual Studio.
3. Build and run the project.

The app saves tasks locally in a todos.json file when you click Save and confirm it. Saved tasks are loaded when the app starts.
